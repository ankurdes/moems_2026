1Martian truth days
Answer: Every day except Saturday
  1. Check each day. On a truth day the statement must be true, so tomorrow must be a lie day. On a lie day the statement must be false, so tomorrow must be a truth day.
  2. Monday (truth): Tuesday is a lie day ✓. Wednesday: Thursday is a lie day ✓. Friday: Saturday is a lie day ✓.
  3. Tuesday (lie): Wednesday is a truth day ✓. Thursday: Friday is a truth day ✓. Sunday: Monday is a truth day ✓.
  4. Saturday (lie): Sunday is also a lie day, so the statement would be true, and a liar can't say something true ✗.
  5. So the answer is every day except Saturday.
⚡ Trick: For truth and lie puzzles, make a small table and test every case. Don't try to reason it all in your head.

2Patterns
Answer: 1014
  1. Group the terms in pairs: (2027 − 2026) + (2025 − 2024) + ... + (3 − 2), and then the final + 1 is left over.
  2. Each pair equals 1.
  3. The pairs use the numbers 2027 down to 2, which is 2026 numbers, so there are 2026 ÷ 2 = 1013 pairs.
  4. Total = 1013 + 1 = 1014.
⚡ Trick: Long alternating sums: pair the terms, count the pairs, and watch for a leftover term at the end.
3Inequalities

  2. n2 must be less than 70. 82 = 64 works and 92 = 81 doesn't.

4Factors
Answer: 6
  1. Every factor has the form 3a × 5b with a from 0 to 4 and b from 0 to 2. That gives 5 × 3 = 15 factors in total.
  2. List them in a small grid. Powers of 3 are 1, 3, 9, 27, 81. Times 5 gives 5, 15, 45, 135, 405. Times 25 gives 25, 75, 225, 675, 2025.
  3. The two-digit ones are 27, 81, 15, 45, 25 and 75.
  4. That's 6.
⚡ Trick: Use the prime factorization to build every factor in an organized grid, rows by one prime and columns by the other. Then nothing gets missed.
5Percent
Answer: 40
  1. 7.5% = 7.5/100 = 75/1000 = 3/40 in lowest terms.
  2. The number of chess students is 3/40 of the school, which has to be a whole number.
  3. So the school size must be a multiple of 40. The least is 40 (with 3 chess students).
⚡ Trick: "Exactly p%" problems: write the percent as a fraction in lowest terms. The denominator is the smallest possible group size.
6Probability
Answer: 40
  1. There are 5 × 4 = 20 equally likely pairs.
  2. The product is a multiple of 3 only if one of the numbers is. From the first set that's only 3, and from the second set only 6.
  3. Pairs with 3 from the first set: 4. Pairs with 6 from the second set: 5. The pair (3, 6) was counted twice, so 4 + 5 − 1 = 8.
  4. 8 out of 20 = 40%, so K = 40.
⚡ Trick: For "multiple of 3" in a product, only the factors that are multiples of 3 matter. Count them, and subtract any pair you counted twice.
7Geometry
Answer: 216
  1. Let each small rectangle be w wide and h tall. Its perimeter: 2(w + h) = 30, so w + h = 15.
  2. MATH is 4w wide and h tall: 2(4w + h) = 66, so 4w + h = 33.
  3. Subtract the first equation from the second: 3w = 18, so w = 6 and h = 9.
  4. MATH is 24 by 9, so the area is 216.
⚡ Trick: Name the small sides with letters, write one equation for each perimeter you're given, then subtract the equations to get rid of one letter.
8Geometry
Answer: 54
  1. The top triangle and the bottom triangle both have the rectangle's width as their base. Their heights add up to the rectangle's full height.
  2. So top + bottom = ½ × width × height = half the rectangle, no matter where P is.
  3. The same is true for left + right. So top + bottom = left + right.
  4. 47 + 36 = 29 + N, so 83 = 29 + N and N = 54.
⚡ Trick: For any point inside a rectangle, the two triangles on opposite sides always add up to half the rectangle. You don't need to know where the point is.
9Rates
Answer: 52
  1. With the tailwind the plane's speed is 300 + 50 = 350 mph. With the headwind it's 300 − 50 = 250 mph.
  2. Going: 700 ÷ 350 = 2 hours. Coming back: 700 ÷ 250 = 2.8 hours.
  3. Total: 4.8 hours = 4 hours and 0.8 × 60 = 48 minutes.
  4. H + M = 4 + 48 = 52.
⚡ Trick: Wind problems: add the wind speed going with it and subtract going against it. Then time = distance ÷ speed for each leg. Never average the two speeds.
10Cryptarithm
Answer: 8
  1. AB means 10A + B, and BA means 10B + A.
  2. Add them: 11A + 11B = 11(A + B).
  3. For 11(A + B) to be a perfect square, A + B must contain another 11, so A + B = 11 (A + B is at most 18).
  4. Then AB + BA = 121 = 11². The digits that add to 11 give 29, 38, 47, 56, 65, 74, 83, 92.
  5. That's 8 numbers.
⚡ Trick: Write digit numbers as 10A + B. Adding or subtracting reversed numbers always gives a multiple of 11 (sum) or of 9 (difference).
